常見問題

App 需要網路嗎？

不需要。內建超過 7,000 字與 200 片語的字典、單字庫、間隔複習、本機測驗、文法庫與經典名句全部離線可用。只有 AI 生成功能（出題、翻譯、作文批改等）在使用雲端模型時需要網路；使用 Apple Intelligence 本機模型則完全離線。

免費版有什麼功能？

免費版包含完整的離線字典、單字庫管理、間隔重複複習、本機單字測驗（中譯英／聽力拼字／英譯中）、內建文法庫、經典名句。AI 智慧功能（出題、閱讀文章、作文批改、翻譯、問 AI）需要購買完整版。

購買完整版後可以在多台裝置使用嗎？

可以。使用同一個 Apple ID 登入的所有裝置都可以使用，在新裝置上點「回復購買」即可。

如何備份我的學習資料？

  • iCloud 自動備份：在設定頁開啟「iCloud 自動同步備份」，App 會自動備份到您的 iCloud
  • 手動匯出：設定 → 備份 → 匯出，會產生 JSON 檔案可另存

AI 模型怎麼選？

  • Apple Intelligence（推薦新手）：免費、離線、不需設定，但品質較基本（需 iOS 26+ 且裝置支援）
  • 遠端模型：到各供應商申請 API Key 填入設定頁即可使用。推薦 Anthropic Claude 或 OpenAI GPT 品質最好

API Key 安全嗎？

API Key 只存在您裝置的 Keychain（iOS 最安全的儲存區），不會上傳到任何伺服器、不會出現在備份檔中。

為什麼有時 AI 會顯示「格式不正確」？

AI 模型偶爾會回傳不完整的回應，App 會自動重試一次。如果持續發生，可以嘗試：換一個模型、稍後再試、或切換到 Apple Intelligence 本機模型。

系統需求

  • iOS 18.6 或以上
  • Apple Intelligence 功能需要 iOS 26 以上且裝置支援
  • 約 50 MB 儲存空間
