常見問題

App 需要網路嗎？

核心學習功能可離線使用：內建字典、單字庫、間隔複習、本機測驗、文法庫與經典名句都不需要網路。使用雲端 AI（例如 Anthropic、OpenAI、Google、xAI、DeepSeek、Qwen 或 OpenCode Zen）時需要網路；Apple Intelligence 本機模型則需要 iOS 26 以上、支援的裝置與已啟用的 Apple Intelligence。

免費版有什麼功能？

免費版包含完整的離線字典、單字庫管理、間隔重複複習、本機單字測驗（中譯英／聽力拼字／英譯中）、內建文法庫、經典名句。AI 智慧功能（出題、閱讀文章、作文批改、翻譯、問 AI）需要購買完整版。

購買完整版後可以在多台裝置使用嗎？

可以。使用同一個 Apple ID 登入的新裝置，開啟 App Store 的「回復購買」即可恢復已購買的完整版功能；實際可用性仍以 Apple 的購買紀錄與家庭共享設定為準。

如何備份我的學習資料？

  • iCloud 自動備份：在設定頁開啟「iCloud 自動同步備份」，備份會儲存到您自己的 iCloud
  • 手動匯出：設定 → 備份 → 匯出，會產生 JSON 檔案，請自行選擇安全位置保存

AI 模型怎麼選？

  • Apple Intelligence：免費、裝置端處理，但品質較基本（需 iOS 26+、裝置支援且已啟用）
  • 遠端模型：到各供應商申請 API Key 填入設定頁即可使用；OpenCode Zen 也提供免 API Key 的模型

API Key 安全嗎？

API Key 只存在您裝置的 Keychain，不會上傳到 GSAT-AI 開發者的伺服器，也不會出現在 App 的 iCloud／JSON 備份檔中。使用遠端 AI 時，您輸入的內容會直接送到所選供應商，請參閱該供應商的隱私政策。

為什麼有時 AI 會顯示「格式不正確」？

AI 模型偶爾會回傳不完整的回應，App 會自動重試一次。如果持續發生，可以嘗試：換一個模型、稍後再試、或切換到 Apple Intelligence 本機模型。
